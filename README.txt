¿Cómo levanté el proyecto?
1- Creé un repositorio con el nombre est-web-2025-unl.
2- Subí la plantilla original al main usando la consola de Git en la carpeta correspondiente con los siguientes comandos:
git init
git add .
git commit -m "First commit"
git remote add origin [link del repositorio]
git push origin main
3- Creé la rama first-version para subir mi versión modificada:
git checkout -b first-version
4- Hice mis modificaciones y los push
git push origin first-version
5- Activé Github Pages desde la configuración, seleccionando la rama first-version para que publique esa.
